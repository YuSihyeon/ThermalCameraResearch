# 열화상 실시간 처리 실측

현재 색상 보존 기능을 포함한 결과는 [최신 측정](thermal_color_runtime_results.md)을 참고한다.

측정일: 2026-10-08. **아래 수치는 카메라 고온 외곽선 기능 추가 전 코드의 기록이다.** 측정 당시 소스는 `experiments/teed_ui/thermal_runtime/measured_source`에 해시와 함께 보존되어 있다. 현재 PC에서 새 윤곽 안정화를 포함한 전체 경로는 15/30fps 실시간 조건을 충족하지 못한다. 기존 WebM의 29.97fps는 파일의 재생 속도다.

## 조건

Core Ultra 7 258V / Windows / PyTorch 2.13.0+cpu / OpenCV 4.14.0. CUDA 사용 불가. TEED 입력 320×256, HUD 720×405, 소스는 3840×2160 열화상 동영상이다. 최종 비교는 Torch/OpenCV 4스레드, 디코더 1스레드, 배치 1을 사용했다. 프로세스 CPU affinity는 고정하지 않았다.

각 조건에서 연속 20프레임으로 전체 파이프라인을 예열한 뒤 120프레임을 측정했다. IFSI4는 300–419, IFSI8은 90–209프레임이다. 추론 결과 캐시·프레임 건너뛰기·재생 속도 제한 없이 순차 처리했다. 생성된 HUD 버퍼도 확인했다.

## 최종 4스레드 결과

| 영상 | 윤곽 추적 | 영상 읽기 포함 FPS | 평균 읽기 | 평균 TEED 전체 | 평균 HUD | 처리 전체 p95 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| fire360_ifsi4 | 꺼짐(확률 안정화) | 7.78 | 30.0ms | 33.8ms | 64.7ms | 149.3ms |
| fire360_ifsi4 | 켜짐 | 3.36 | 29.0ms | 34.0ms | 234.6ms | 382.4ms |
| fire360_ifsi8 | 꺼짐(확률 안정화) | 7.44 | 31.8ms | 37.8ms | 64.8ms | 168.5ms |
| fire360_ifsi8 | 켜짐 | 3.86 | 30.3ms | 34.1ms | 195.0ms | 341.2ms |

TEED 신경망 연산 자체는 평균 18.1–21.7ms, 전처리·후처리까지 포함한 TEED 단계는 33.8–37.8ms였다. 새 윤곽 추적이 포함된 HUD만 195.0–234.7ms이므로 모델 추론 가속만으로 전체 경로가 15/30fps를 충족한다고 볼 수 없다. 4개 조건 모두 모든 측정 프레임이 15fps의 66.7ms 및 30fps의 33.3ms 시간 예산을 초과했다.

## 실제 실행 경로 확인

운영 진입점 `edge/orin/run_pipeline.py --headless --contour-edges`로 IFSI8의 120프레임을 별도로 실행했다. 완료했고 처리율은 4.04fps, 추론+HUD 평균 222.6ms, p95 296.3ms였다. 이 CLI의 `e2e` 필드는 영상 읽기와 실제 화면 표시를 포함하지 않으므로 센서부터 디스플레이까지의 지연으로 해석하면 안 된다.

## 검증 범위와 제한

- 최종 표는 다른 벤치마크 프로세스가 종료된 뒤 순차 실행한 4스레드 결과다. 초기 1스레드 IFSI4 결과에는 동시 CPU 벤치마크 영향 가능성이 있어 최종 모드 간 비교에 사용하지 않았다.
- 영상 읽기·추론·HUD 버퍼 생성까지 측정했고 인코딩, 실제 카메라 캡처, HMD 표시·스캔아웃은 제외했다. 라이브 카메라 입력 구조가 있다는 사실과 실시간 속도 충족은 별개다.
- 영상 소스 시간으로 안정화 상태를 갱신했다. 느린 실시간 입력의 버퍼 누적·프레임 폐기 정책을 검증한 시험은 아니다.
- 실행 가능한 Jetson 접속 정보가 확인되지 않아 Orin/GPU 성능은 측정하지 않았다. PC 값을 Jetson 성능으로 환산하지 않는다.
- 이 측정 당시에는 벤치마크 스크립트만 추가했고 구현·가중치를 바꾸지 않았다. 이후 고온 외곽선 기능으로 HUD가 변경되었으므로 최신 코드 성능과 구분한다. Ruff와 Basedpyright 검사는 통과했다.

원시 측정은 로컬 생성 기록 `experiments/teed_ui/thermal_runtime/benchmark.json`, 실제 CLI 기록은 `experiments/teed_ui/thermal_runtime/cli_contour_smoke.json`에 있다. 이 JSON은 GitHub 배포 대상이 아니다. 재현 코드는 [benchmark_thermal_runtime.py](../experiments/teed_ui/benchmark_thermal_runtime.py)이다.
