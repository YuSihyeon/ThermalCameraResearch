# Fire360 로컬 열화상 영상: 촬영 장비 추적과 고온 영역 검출 가능성

조사일: 2026-10-08. 범위: 로컬 data/fire360/raw의 7개 파일 중 IFSI Video 4/8 열화상 표시 영상. 공개 Fire360 전체 다운로드 목록은 대조하지 못했으므로 이 결과를 전체 데이터셋에 일반화하지 않는다.

## 결론

- IFSI Video 4/8은 일반 360도 영상과 별개인 열화상 표시 영상이다. 화면 눈금과 팔레트가 **Seek Thermal 계열** 문서와 일치하며 **FirePRO 300은 유력 후보**다. 모델명 직접 증거가 없어 정확한 모델은 미확정이다.
- **실제 IFSI Video 4에서 컬러로 표시된 고온 후보 영역을 분리했다.** 전체 625프레임 중 163프레임에 후보가 있었다. Video 8은 661프레임 중 0프레임이었다.
- 이 검사는 색상 표시를 읽는 방법의 가능성을 확인한 것이다. 화재 정답 라벨과 비교하지 않았으므로 탐지율·정확도·재현율로 해석하면 안 된다.
- 정밀한 픽셀별 섭씨값을 복원할 근거는 없지만, 장비와 Fire Mode가 확인되면 고정 팔레트의 대략적인 온도 구간을 활용할 수 있다. 앞선 “온도 정보를 전혀 알 수 없다”는 표현은 너무 넓은 단정이다.
- 결과는 오프라인 조사·시각화이며 이번 조사에서 운영 HUD에 새 열화상 검출 경로를 통합하지 않았다.

## 장비 추적 근거와 신뢰도

| 근거 | 관찰 | 해석 |
|---|---|---|
| 화면 우측 눈금 | 300 / 575 / 850 / 1025, 녹색 숫자 | Seek 공식 Fire Mode 눈금과 정확히 일치. 섭씨가 아니라 화씨 눈금으로 해석하는 것이 문서와 부합 |
| 화면 배색 | 흑백 장면, 고온부 노랑·주황, 우측 컬러 바 | Seek Fire Mode 표시와 부합 |
| MP4 트랙 | avc1 영상 + mp4a 오디오 | 확인한 트랙에 별도 온도 데이터 스트림 없음 |
| XMP | Adobe Premiere Pro 2021.0 (Windows), H.264 | 편집·내보내기 파일임을 뒷받침 |
| XMP 생성 기록 | Video 4: 2023-10-03, Video 8: 2023-10-06 | 편집 시점의 메타데이터이며 실제 촬영일 확정은 아님 |
| 원본 참조 | 두 파일 모두 video26.mp4 | 동일 원본일 가능성이 있어 독립 학습/검증 표본으로 자동 취급하면 안 됨. 파일명만으로 동일성 확정은 불가 |
| 제조사/모델 태그 | 확인한 XMP에 없음 | 정확한 모델 확정 불가 |
| 제품 출시 시점 | FirePRO 300: 2023-04-27, FirePRO 200: 2024-06-06 | 메타데이터 날짜가 맞다면 300은 가능하며 200은 가능성이 낮음 |

Seek 계열 추정 신뢰도는 중상, FirePRO 300 정확 모델 추정은 중간 이하로 본다. AttackPRO 등도 유사 눈금을 공유한다. 편집 영상이므로 MP4라는 사실만으로 카메라의 자체 녹화 기능까지 단정할 수 없다.

[Fire360 논문 §3](https://arxiv.org/html/2506.02167v1)은 Ricoh Theta V를 명시하지만, IFSI 파일별 열화상 장비명을 명시하지 않는다. Ricoh는 가시광 360도 카메라이며 해당 설명으로 이 열화상 영상의 장비를 판단해서는 안 된다. [Ricoh 공식 사양](https://theta-archive.ricoh360.com/support.theta360.com/ko/manual/v/content/add_info/add_info_01.html)

Seek 화면 비교 근거: [FirePRO 300 매뉴얼, Fire Mode](https://www.thermal.com/uploads/1/0/1/3/101388544/firepro300_rev3.pdf), [AttackPRO 매뉴얼](https://www.thermal.com/uploads/1/0/1/3/101388544/attackpro_user_manual_en_de_es_fr_jp.pdf). 출시 시점: [Seek 공식 보도자료 목록](https://www.thermal.com/press.html).

## 온도 정보는 어디까지 사용할 수 있는가

Seek Fire Mode라는 전제에서 제조사가 설명하는 구간은 다음과 같다. 제조사 문서의 반올림된 섭씨 대응이며 실제 프레임의 측정값이 아니다.

| 표시 | 제조사 설명의 대략적인 구간 |
|---|---|
| 회색 | 약 150°C 미만. 밝기는 장면 범위에 따라 조정되므로 밝기만으로 섭씨값 환산 불가 |
| 흰색 → 노랑 | 약 150–300°C |
| 노랑 → 주황 | 약 300–450°C |
| 주황 → 빨강 | 약 450–550°C 이상 |

[Seek 공식 FAQ의 TI BASIC/TI BASIC+ 설명](https://support.thermal.com/hc/en-us/articles/20630497344275-FirePRO-Series-Frequently-Asked-Questions)에 근거한다. Fire Mode와 Survey Mode는 색상 기준이 다르다. 이 표를 일반 RGB 영상이나 다른 열화상 팔레트에 적용하면 안 된다.

흰색은 저채도 고온 구간과 밝은 회색이 겹칠 수 있다. 따라서 이번 유색 픽셀 검출이 약 150°C 이상인 모든 픽셀을 포괄하지 않는다. 압축, 리사이즈, 팔레트 경계, 편집 효과도 오차 원인이다. 개별 픽셀을 예컨대 327°C처럼 표시하거나 정밀 등온선을 그리는 근거로 사용할 수 없다.

## 실제 파일 검사

1286프레임을 모두 순차 디코딩했다. 3840×2160 영상을 960×540으로 축소한 뒤 다음 조건을 적용했다.

- 영상 바깥 검은 여백, IFSI 로고, 우측 색상표와 숫자를 고정 사각형으로 제외.
- OpenCV HSV 기준 H ≤ 38 또는 H ≥ 175, S ≥ 60, V ≥ 80인 빨강·주황·노랑 후보.
- 연결 영역 면적 8픽셀 이상 유지. 이 임계값은 표시용 색상 탐색 기준이며 섭씨 임계값이 아니다.
- 시간적 추적이나 학습 모델 없이 프레임별 팔레트 분리 가능성을 검사.

| 영상 | 디코딩 | 후보가 있는 프레임 | 최대 후보 면적 |
|---|---:|---:|---:|
| IFSI Video 4 | 625 / 625 | 163 | 11,943픽셀 / 960×540 |
| IFSI Video 8 | 661 / 661 | 0 | 0 |

Video 4의 481번 프레임에서는 왼쪽 용기 표면의 노란 영역이 빨간 윤곽으로 분리되고, 주변 소방관과 흰 벽은 화점으로 칠해지지 않았다. 이 영역은 **장비가 고온으로 색상화한 영역 후보**이며 실제 불꽃 또는 최초 발화 지점이라는 정답은 확인되지 않았다.

Video 8의 유효 장면은 검사한 전체 프레임에서 RGB 채널 간 차이가 최대 19/255였다. 흑백 밝은 부분을 임의로 빨갛게 칠하지 않는 동작을 확인했다. 0건은 고온·화재 부재의 증명이 아니다. 가림, 팔레트 적용 여부, 제외된 화면 영역 등의 영향을 받는다.

원본·검출 예시: 로컬 생성 이미지 `experiments/teed_ui/thermal_research/thermal_feasibility.png`. 이 이미지는 GitHub 배포 대상이 아니다.

재현 코드: [inspect_thermal_sources.py](../experiments/teed_ui/inspect_thermal_sources.py)

전체 프레임별 결과·메타데이터·SHA-256: 로컬 생성 기록 `experiments/teed_ui/thermal_research/thermal_source_audit.json`. 이 JSON은 GitHub 배포 대상이 아니다.

실행은 저장소 루트에서 부모 환경의 Python으로 experiments/teed_ui/inspect_thermal_sources.py를 실행한다. --render-only 옵션은 저장된 JSON으로 대표 프레임 그림만 다시 만든다.

## UI 적용 판단

**“화점”을 고온 위험 영역이라는 의미로 표시하는 개발은 가능하다.** 이 영상에는 밝기보다 근거가 좋은 고정 팔레트 신호가 일부 존재한다. 권장 처리 순서는 장면/OSD 구분 → 입력 모드 확인 → 고온 색상 구간 분리 → 작은 영역 정리 → 시간적 안정화 → 얇은 위험 윤곽 표시다.

정밀 섭씨 등온선 대신 확인된 팔레트 구간의 경계를 표시하고, 실제 불꽃 판별은 별도 근거로 다룬다. 뜨거운 용기·벽·반사도 고온 후보가 될 수 있다. 제조사 매뉴얼 역시 열원과 반사 구별, 물·연기 등으로 가려지는 상황을 설명한다.

“잘 탐지한다”는 성능 결론에는 사람이 검수한 고온 영역/화염 라벨, 밝은 비화재 장면, 가림 장면이 필요하다. 누락률, 오경보/분, 경계 IoU, 표시 지연을 원본 영상 단위로 분리한 검증 세트에서 평가해야 한다. 이번 두 짧은 클립과 색상 분리 결과만으로 현장 성능을 주장하지 않는다.

추가 확인: GOPR8356 (2).MP4는 실제 프레임과 GoPro 컨테이너 핸들러에서 가시광 영상임을 확인했다. 기존 로컬 video_profiles.json의 고정 열화상 OSD 분류는 이 파일과 맞지 않는다. 해당 공유 데이터 설정은 이번 조사에서 수정하지 않았으며, 입력 자동 분류를 구현할 때 반드시 교정해야 한다.
