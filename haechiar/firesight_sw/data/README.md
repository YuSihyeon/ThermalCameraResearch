# 데이터

데이터를 촬영하고 수집 기록을 관리하는 파일을 모은다.

| 폴더 | 내용 |
| --- | --- |
| [capture/boson/](capture/boson/README.md) | Boson 320 녹화·미리보기·점검·로그 정리·압축 도구 |
| [collection/](collection/README.md) | 날짜별 촬영계획, 결과 요약, 현장로그, 녹화 메타데이터와 원본 보관 안내 |

원본 TIFF 프레임은 기존처럼 별도 보관한다. 위치와 압축파일 확인 방법은
[수집 기록 안내](collection/README.md)에 있다.

윤곽선 처리는 [edge/](../edge/README.md), 깊이 추정은 [depth/](../depth/README.md),
비교 실험과 검증 스크립트는 [experiments/](../experiments/)에서 찾는다.
