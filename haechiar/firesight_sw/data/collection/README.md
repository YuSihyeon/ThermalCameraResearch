# 촬영 데이터

이 배포본에는 Boson 촬영·점검 코드가 포함되어 있습니다. HaechiAR의 실제 촬영 세션,
raw TIFF, 현장 로그와 메타데이터는 함께 복제하지 않았습니다.

- [촬영·점검 도구](../capture/boson/README.md)
- [기존 공개 영상](../../../../public-media/)
- [보존된 연구 결과와 데이터 복원 안내](../../../../DATA_AND_RESTORE.md)
- [기준 커밋의 수집 기록](https://github.com/HaechiAR/firesight_sw/tree/339af10729a5be5436c63cc74324585e1f97777e/data/collection)

새 촬영은 별도 폴더를 만들고 `BOSON_SHOOT_DIR`로 지정합니다.
촬영 순서표를 사용할 경우 필요한 열은 촬영 도구 README에 정의되어 있습니다.
