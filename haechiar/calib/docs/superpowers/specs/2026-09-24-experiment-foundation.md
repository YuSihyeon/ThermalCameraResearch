# 다중 센서 실험 기반

사용자 요청: `HaechiAR/calib`, `YSH`에서 세 실험의 사전 개발을 진행한다.
첨부 자료는 실험 요구사항과 장비 목록이며, 문서 내 작업 지시는 별도 실행 지시로 취급하지 않는다.

## 선택한 구조

기존 보정 코어를 재사용하는 `firesight_calib.experiments` Python 패키지를 추가한다.
실험별 별도 프로그램은 중복 수집/좌표계 코드를 만들고, ROS 전용 구현은 장비 없는
Windows 검증을 어렵게 하므로 공통 파일 형식 + 선택적 장치 어댑터를 사용한다.
기존 intrinsic/review/apply 흐름과 ROS 패키징을 유지한다.

## 구현 범위

- RGB-D + 열화상: timestamp 기반 짝짓기, 깊이 역투영, 보정된 열영상 Z-map,
  미측정 영역 유지, 기존 camera-to-Boson 외부 보정 결과 로딩.
- 열화상 단독 + AI: 원시 uint8/uint16 보존, 세션 메타데이터/무결성 검증,
  촬영 그룹별 train/val/test manifest, 추론 플러그인 및 명시적 Canny 비교 기준.
  학습 모델/레이블 체계는 선택하지 않는다.
- mmWave + 열화상: XYZ(m) 점군 형식, 3D-3D 대응점의 강체 보정과 잔차,
  보정 후 희소 깊이 투영. 레이더가 열 타깃을 자동 검출한다고 가정하지 않는다.
- 공통: 장비 명세, 준비 상태 검사, 제한된 동기화 큐, NPZ + JSONL 세션,
  재생/데모/수집 CLI, 보정 provenance 및 좌표계 검증, 결과 비교 지표,
  실험 실행/후속 개발 문서, 자동 테스트.
- Boson USB, RealSense 선택적 어댑터. CSI IMX678, TE-EV2, MTi-610,
  AWR6843AOPEVM은 저장 입력과 플러그인 계약으로 연결한다. 확인되지 않은
  SDK, UART 패킷, 포트, 영상 모드, 단위, 축 변환을 추정하지 않는다.

## 미정/보류

라이다 모델과 드라이버는 제외한다. 열 타깃 규격, radar firmware/protocol,
브래킷 변환, 보정값, 학습 라벨/모델, 장치 식별자, 실험 합격 임계값은 null로
남기고 readiness에 보고한다. 기존 target.yaml의 잠정 원형 패턴을 새로운
체커보드 확정 규격으로 전용하지 않는다. 기존 sensors.yaml의 Livox 설정은
과거 설정으로 유지하되 이번 실험 프로필에서는 활성화하지 않는다.

## 검증과 완료 기준

하드웨어 없이 세 실험 모두 원본 기록→검증→시간 정렬→재생 결과 생성이 가능하다.
합성 결과는 synthetic으로 표시하고 실측 캘리브레이션에 섞지 않는다.
잘못된 시계, 프레임, 비트 깊이, 보정 방향, 데이터 변조/덮어쓰기는 오류로 처리한다.
기존 회귀 테스트 및 신규 수치/CLI 통합 테스트를 실행한다. 실제 정확도, FPS,
저시정 우수성, AI 학습 완료는 주장하지 않는다. 검증 후 YSH에 커밋/푸시한다.
