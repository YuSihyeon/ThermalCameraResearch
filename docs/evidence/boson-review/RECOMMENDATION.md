# 초록색 윤곽선 추천 결론: Balanced · 출력 2픽셀

2026-09-08 · YSH 영상 비교 결과

**다음 장비 시연·가독성 비교의 우선 설정으로 `thin / balanced / 출력 2픽셀`을 추천한다.**
이번 640×480 모니터 출력에서 1픽셀보다 선을 알아보기 쉽고, 기존 굵은 선보다
배경을 적게 가렸다. 실제 AR 안경의 최종 설정은 장비 비교 후 확정한다.

## 무엇을 선택한 것인가

| 항목 | 추천값 | 역할 |
|---|---|---|
| 경계 처리 | `--edge-style thin` | 선택한 경계를 중심선으로 정리 |
| 상세도 | `--detail balanced` | low 0.60 / high 0.85로 연결된 경계를 선별 |
| 표시 굵기 | `--line-width 2` | 최종 출력 이미지에서 선을 2픽셀 폭으로 표시 |

Balanced 1픽셀과 2픽셀은 같은 경계를 선택한다. 2픽셀은 표시 폭만 늘리므로
검출 정보를 더 추가하지 않는다. Detailed는 약한 경계를 더 남기고,
Sparse는 더 적게 남긴다. 이 설정은 물체 종류나 장애물 중요도를 판단하지 않는다.

## 추천 근거

HUD 합성 전 SmokeBasement 농연 열화상 표시 영상 12초·120프레임을 같은 TEED
확률맵으로 비교했다. 출력은 640×480이며 배경 밝기 비율은 0.24다.

| 설정 | 평균 초록선 점유율 | 선택 판단 |
|---|---:|---|
| 기존 legacy | 11.50% | 이번 비교에서 선이 넓어 배경을 많이 가림 |
| Balanced · 1픽셀 | 1.18% | 가늘지만 이번 모니터 검토에서 2픽셀보다 덜 눈에 띔 |
| **Balanced · 2픽셀** | **2.63%** | **선의 가시성과 배경 노출을 함께 고려한 우선 시험안** |

점유율은 화면에서 선이 차지하는 면적이며 검출 정확도 점수가 아니다.
Detailed/Sparse를 포함한 비교 조건과 시간 변화 검토는 [영상 검증 보고서](VIDEO_CHECK.md)에 있다.

## 적용 방법

저장소 루트에서 HUD 합성 전 회색 열화상 영상을 사용한다.
`original_thermal.mp4`는 실제 입력 파일 경로로 바꾼다.

```bash
python edge/orin/run_pipeline.py --source original_thermal.mp4 \
  --sensor-modality thermal_gray --device cpu --pace \
  --edge-style thin --detail balanced --line-width 2 \
  --display-width 640 --display-height 480 --no-panel
```

핵심 적용 옵션은 `--edge-style thin --detail balanced --line-width 2`다.
기존 장비 실행 명령에 적용할 때는 구 옵션 `--threshold`, `--edge-width`를 제거한다.
출력 픽셀 기준이므로 안경에서는 실제 출력 해상도로 맞춘 뒤 1픽셀과 2픽셀을 비교한다.
런타임 기본값은 현재 `thin / balanced / 1픽셀`이며, 이번 추천은 명시적 옵션으로 적용한다.

## 장비에서 결론을 확정할 조건

- 같은 경로·장면에서 1픽셀과 2픽셀을 비교해 문틀·바닥 경계·먼 장애물의 가독성을 확인한다.
- 선이 시야를 가리는지, 약한 경계가 누락되는지 함께 확인한다. 약한 경계 누락은 굵기와 별도로 상세도를 비교한다.
- 고개 이동 때 짧은 선의 깜빡임과 실제 Jetson 지연시간을 확인한다. 이번 변경으로 시간 안정성이 해결된 것은 아니다.

첨부 `boson_test.mp4`는 이미 초록선이 합성된 영상이므로, 위 상세도 추천의 직접 검증
자료로 사용하지 않았다. 해당 Boson에서 새 검출 결과를 평가하려면 합성 전 입력이 필요하다.
이번 결론의 범위는 초록선 표시이며 RGB 화재 판단이나 Boson 고온 후보 검출은 포함하지 않는다.
